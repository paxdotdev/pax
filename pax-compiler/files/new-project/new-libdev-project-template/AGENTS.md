# Pax Project Instructions

This is a Pax application generated by `pax-cli`.

Start with local CLI docs before changing syntax or architecture:

- `pax-cli docs list`
- `pax-cli docs open "Getting Started"`
- `pax-cli docs open "Template Language & Structure"`
- `pax-cli docs open "Data Binding & Expressions"`
- `pax-cli docs open "Event Handling & Rust Logic"`
- `pax-cli docs search <query>`
- `pax-cli docs examples --list`
- `pax-cli docs examples <example-name>`

Authoring happens in two layers:

- `.pax` files declare UI trees, layout, bindings, events, animation, and style.
- Rust files own application state, event handlers, data loading, platform logic, and side effects.

Pax template expressions inside `{...}` are declarative and side-effect free. Use Rust event handlers for state changes and external effects.

Before handing off meaningful UI work, run a web build:

```sh
pax-cli build --target=web
```
