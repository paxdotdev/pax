# Bundled fixture fonts

These unmodified font files are from [Google Fonts](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33). They preserve this fixture’s original type families without a runtime network request. The SIL Open Font License and copyright notice for each family are included alongside the files.

Variable fonts retain their upstream axes; Pax selects family/style/weight through its ordinary font API.
