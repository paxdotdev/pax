### `ClickOrTap`
A ClickOrTap describes either a "click" (mousedown followed by mouseup), OR a
"tap" with one finger (singular fingerdown event).
ClickOrTap is a useful alternative to most kinds of `Click` or `Tap` events,
when you want the same behavior for both to be contained in one place.

#### Properties
##### `x`
Type: `f64`

The x-coordinate of the click_or_tap in the receiving node's local coordinate space.

##### `y`
Type: `f64`

The y-coordinate of the click_or_tap in the receiving node's local coordinate space.

### `Event`
Event wrapper passed to Pax event handlers.

`Event<T>` carries the typed event payload and shared cancellation state,
allowing handlers to call `prevent_default` where the active chassis supports it.

#### Properties
##### `args`
Type: `T`

The event-specific payload, for example `Click` or `KeyDown`.

#### Implementations
##### `new`
<pre><code class="api-signature language-rust ignore">pub fn new(args: T) -&gt; Self</code></pre>

Constructs an event wrapper around a raw payload.

##### `prevent_default`
<pre><code class="api-signature language-rust ignore">pub fn prevent_default(&amp;self)</code></pre>

Cancels the platform default for this event, when the chassis supports cancellation.
